
🇫🇷 **フランス語基本単語・例文学習 Web アプリケーション**
全45セクション（560例文・見出し語2,223語・総合語彙11,515項目・日常生活語彙集・高音質ニューラル音声）をスマートフォンおよびPCブラウザで快適に学習できるWebアプリです。

## 🌐 GitHub Pages 公開 URL
**[https://kelvicc.github.io/French-Vocabulary/](https://kelvicc.github.io/French-Vocabulary/)**

## ✨ 主な機能
- **スマホ最適化 2カラムレイアウト**: 左列に見出し語・発音記号（IPA結合文字完全対応）、右列に品詞・意味・派生語・語源メモを配置。
- **高音質ニューラル音声**: 全560例文のネイティブ発音を即座に再生（単曲再生、連続再生、スピード調整対応）。
- **確認クイズ（2つの異なる形式）**:
  - 【本編 01〜45】**仏 ➔ 和クイズ**: 重要単語の意味を4択で確認。
  - 【日常語 Theme 01〜08】**和 ➔ 仏 冠詞・性別ランダムクイズ**: 日本語からフランス語の単語・冠詞（le/la/un/une）・文法性（男/女）をアクティブ想起＋ネイティブ音声自動再生。
- **ダークモード完全対応**: 右上の月/太陽アイコンで、目に優しいナイトモードへ瞬時に切り替え（設定はブラウザに記憶）。
- **完全スタンドアロン型**: HTML/CSS/JS/全語彙データを1ファイルに統合、瞬速起動とオフライン動作を実現。
